# github-stats

Daily snapshots of GitHub traffic statistics for my public repositories —
unique/total views, unique/total clones, top referrers, top paths, plus
stargazer and fork evolution — preserved beyond GitHub's built-in 14-day
traffic window.

**Live reports:** https://martenzi.github.io/github-stats/

Data (CSV snapshots + HTML/PDF reports) accumulates on the
[`github-repo-stats`](https://github.com/martenzi/github-stats/tree/github-repo-stats)
branch, one folder per tracked repo.

Powered by [jgehrcke/github-repo-stats](https://github.com/jgehrcke/github-repo-stats),
running daily via GitHub Actions.
